# Навыки из obra/superpowers

Скопированы из https://github.com/obra/superpowers (коммит 8ca22db, лицензия MIT — SUPERPOWERS-LICENSE).
Для работы над кодом репозитория (шлюз wagate, агент camirix):

- `systematic-debugging` — сначала найти причину ошибки, потом чинить;
- `test-driven-development` — сначала тест, который падает, потом код;
- `verification-before-completion` — не говорить «готово», пока проверка не запущена и не прошла.
