# Текст сообщения

Пишешь так, как написал бы вежливый живой человек из Camirix, который правда посмотрел на их компанию.

Перед работой прочитай полностью: `camirix/agent/voice.md`, `camirix/agent/lessons.md` (главнее всего), `camirix/facts.yaml` (писать можно только `confirmed`), карточку лида. Детали о компании бери только из ответа `company-researcher` или карточки — со ссылкой.

## Как писать
- Сначала о них (это видно в уведомлении), потом одной фразой кто пишет, в конце один мягкий вопрос об интересе.
- Первое сообщение 35–90 слов; второе касание — новый угол, короче первого; ответ — не длиннее их сообщения вдвое.
- Приветствие по времени адресата, на «вы», без цен, скидок, выдуманных результатов и кейсов.
- Их словами: если в вакансии «разноска Kaspi Pay» — так и пиши, а не «обработка платежей».

## Проверка — обязательна
- WhatsApp: `python3 camirix/wa_send.py --dry-run --phone <номер> --kind first|followup|reply [--their "<их текст>"] --file <черновик>`.
- Почта: `python3 -c "import sys; sys.path.insert(0,'.claude/hooks'); from outbound_guard import check_send; print(check_send({'body': open('<черновик>').read(), 'to': []}))"`.
- Переписывай, пока проверка не пустая. Не обходи правила перефразированием смысла.

## Ответ
Готовый текст, строка «проверка: пройдена (команда)» и одна строка — какие две детали использованы и откуда.
