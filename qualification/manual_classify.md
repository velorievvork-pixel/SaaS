# Квалификация ответов без единого рубля: через бесплатный чат Claude.ai

При объёме "первые 5–10 клиентов" ответов будет немного (несколько в день максимум) —
разбирать их через бесплатный чат на claude.ai быстрее, чем настраивать автоматизацию.

## Шаги

1. Когда приходит ответ от лида — откройте чат на claude.ai (можно держать один
   постоянный чат для всех разборов подряд, история не мешает).
2. Вставьте промпт ниже, подставив компанию и текст ответа.
3. Claude вернёт категорию и черновик — вы решаете, отправлять черновик как есть,
   поправить или написать самому.
4. Занесите категорию в колонку `Status`/`Notes` вашей CRM (Google Sheet).

## Промпт

```
Ты помогаешь SDR-агентству обрабатывать ответы на холодные сообщения от основателей
и CEO B2B SaaS-компаний.

По тексту входящего ответа определи категорию и напиши короткий черновик ответа.

Категории (выбери ровно одну):
- "Заинтересован" — просит подробности, готов на звонок/встречу, задаёт вопросы
- "Не сейчас" — вежливый отказ с открытой дверью на будущее
- "Не актуально" — явный отказ без намерения продолжать
- "Другое" — автоответ, смена контакта, вопрос не по теме и т.п.

Черновик ответа:
- "Заинтересован" → предложи конкретное время для 15-минутного звонка, коротко.
- "Не сейчас" → поблагодари, спроси, когда уместно вернуться, не дави.
- "Не актуально" → короткая благодарность за ответ, без попытки переубедить.
- "Другое" → короткий уточняющий вопрос или благодарность, по ситуации.

Компания: {{название компании}}
Текст ответа от контакта:
"""
{{вставьте текст ответа}}
"""

Ответь в формате:
Категория: ...
Черновик ответа: ...
```

## Пакетная обработка нескольких ответов сразу

Если накопилось несколько ответов за день — можно вставить их все в одном сообщении
(перечислив компанию + текст для каждого) и попросить Claude вернуть результат по
каждому отдельно, тем же промптом с добавлением: "Вот несколько ответов, разбери
каждый по этим же правилам и верни список".
