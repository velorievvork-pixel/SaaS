# 5. Квалификация входящих ответов

Категории: **Заинтересован** / **Не сейчас** / **Не актуально** / **Другое**.
Для каждой — черновик ответа. Решение отправлять или нет — **всегда за вами**
(на входящих ответах живых людей автоотправку без проверки лучше не включать —
слишком высокая цена ошибки на этапе первых 5-10 клиентов).

## No-code вариант: Make.com free tier

Сценарий:

1. **Gmail — Watch emails** (триггер: новое письмо с определённым лейблом/в ответ на
   вашу рассылку) — бесплатный модуль.
2. **HTTP — Make a request** к Claude API:
   - URL: `https://api.anthropic.com/v1/messages`
   - Headers: `x-api-key: {ваш ключ}`, `anthropic-version: 2023-06-01`,
     `content-type: application/json`
   - Body (JSON): системный промпт + текст письма — см. `prompt.md` в этой папке
3. **JSON — Parse JSON** — достаём из ответа категорию и черновик.
4. **Google Sheets — Update a row** — записываем категорию и черновик в CRM (найти
   строку по email/домену компании).
5. **Telegram Bot — Send a message** (создаётся бесплатно через @BotFather, 5 минут) —
   присылает вам уведомление: "Ответил {компания}: категория {X}. Черновик: {текст}" —
   чтобы вы сразу видели новые ответы в Telegram и могли одобрить/поправить черновик.

Всё это укладывается в бесплатный тариф Make.com (1000 операций/мес) при объёме
"первые 5-10 клиентов" с большим запасом.

## Код-вариант (если удобнее одним скриптом, без Make.com)

`classify_reply.py` делает то же самое из командной строки: подаёте текст ответа,
получаете категорию + черновик. Полезно, если реплаев мало и проще запускать вручную,
чем настраивать сценарий.

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python classify_reply.py "Спасибо, сейчас не актуально, но давайте вернёмся к этому через квартал"
```
