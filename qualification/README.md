# 5. Квалификация входящих ответов

Категории: **Заинтересован** / **Не сейчас** / **Не актуально** / **Другое**.
Для каждой — черновик ответа. Решение отправлять или нет — **всегда за вами**
(на входящих ответах живых людей автоотправку без проверки лучше не включать —
слишком высокая цена ошибки на этапе первых 5-10 клиентов).

## Вариант A (рекомендуемый при нулевом бюджете и малом объёме): вручную через Claude.ai

При нескольких ответах в день проще и быстрее всего разбирать их в бесплатном чате
на claude.ai, без всякой настройки — см. `manual_classify.md`. Стоимость: 0 ₽.

## Вариант B: no-code уведомления через Make.com free tier (тоже 0 ₽)

Имеет смысл, когда ответов становится много и не хочется проверять почту вручную.
Важно: чтобы остаться на 0 ₽, здесь Make.com **только уведомляет**, а классификацию
вы всё равно делаете сами в бесплатном чате claude.ai (промпт из `manual_classify.md`) —
это отличие от Варианта C ниже, где классификацию делает API за деньги.

Сценарий:

1. **Gmail — Watch emails** (триггер: новое письмо, например с определённым лейблом) —
   бесплатный модуль.
2. **Telegram Bot — Send a message** (бот создаётся бесплатно через @BotFather,
   5 минут) — присылает вам в Telegram текст нового ответа сразу, как он пришёл,
   чтобы не проверять почту вручную.
3. Дальше — как в Варианте A: вставляете текст в чат claude.ai, получаете категорию
   и черновик, заносите в CRM.

Укладывается в бесплатный тариф Make.com (1000 операций/мес) с большим запасом при
объёме "первые 5-10 клиентов".

## Вариант C (на будущее, когда появится бюджет): полная автоматизация через Claude API

`classify_reply.py` и HTTP-модуль к `https://api.anthropic.com/v1/messages` в Make.com
делают классификацию автоматически, без копипаста в чат. Это уже **не 0 ₽** — Claude
API тарифицируется по использованию (на объёме "первые 5-10 клиентов" это будут
единицы рублей в месяц, но не ноль). Разумный момент для перехода — когда объём
ответов вырастет настолько, что ручное копирование в чат станет узким местом.

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python classify_reply.py "Спасибо, сейчас не актуально, но давайте вернёмся к этому через квартал"
```
