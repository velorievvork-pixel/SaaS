# 3–4. CRM (Google Sheets) + рассылка + напоминания

Всё бесплатно: Google Sheets + встроенный Apps Script (Extensions → Apps Script в самой
таблице — вставляете код один раз, дальше работает само по расписанию).

## Схема таблицы (лист "Лиды")

| Колонка | Что туда | Пример |
|---|---|---|
| Company | Название компании | ООО Ромашка SaaS |
| Domain | Домен | romashka-saas.ru |
| Contact_Name | Имя основателя/CEO | Иван Петров |
| Contact_Channel | email / telegram / linkedin | email |
| Contact_Value | сам адрес/юзернейм | ivan@romashka-saas.ru |
| Personalized_Line | из `personalization/personalize.py` | (текст) |
| Status | Новый / Написано / Ответил / Пилот / Клиент / Отказ | Новый |
| Status_Date | дата последнего изменения статуса — **заполняется автоматически** скриптом | 2026-09-12 |
| Last_Message_Date | когда отправили последнее сообщение | 2026-09-12 |
| Notes | свободные заметки | "Ответил через 2 дня, интересуется пилотом" |

Статусы вводите через выпадающий список (Data → Data validation) — это исключает опечатки
и даёт скрипту надёжно матчить статусы.

## Apps Script 1: автообновление даты статуса + напоминания о зависших лидах

Файл `apps_script_followup_reminder.gs` — вставьте его целиком в Extensions → Apps Script,
замените `NOTIFY_EMAIL` на свой адрес, сохраните и один раз запустите функцию
`setupTriggers` (Apps Script попросит разрешения — это нормально, это ваш собственный
скрипт в вашей таблице).

Что делает:
- при любом ручном изменении колонки `Status` автоматически проставляет сегодняшнюю
  дату в `Status_Date` (используется триггер `onEdit`);
- раз в день (в 9:00) проверяет все строки: если `Status` не "Клиент"/"Отказ" и прошло
  больше 5 дней с `Status_Date` — присылает вам письмо со списком зависших лидов.

## Apps Script 2 (опционально): рассылка первого сообщения + follow-up

Файл `apps_script_mail_merge_followup.gs` — рассылает email по строкам со статусом
"Новый" (используя `Personalized_Line` + шаблон письма), ставит статус "Написано" и
дату; отдельная функция раз в день проверяет: если статус "Написано" и прошло 3–4 дня
без ответа (в `Status` до сих пор "Написано") — отправляет follow-up и добавляет
пометку в `Notes`, чтобы не отправить дважды.

**Ограничение Gmail на бесплатном аккаунте: ~100 писем/день** — для объёма "первые
5–10 клиентов" этого более чем достаточно. Не увеличивайте объём резко (спам-фильтры),
держите 10–20 писем/день с личного адреса на старте.

Альтернатива без единой строчки кода: надстройка **Yet Another Mail Merge (YAMM)**
из Google Workspace Marketplace — бесплатно до 50 писем/день, есть трекинг открытий.
Follow-up-последовательности в бесплатном тарифе YAMM ограничены — если этого не
хватит, скрипт из этой папки даёт то же самое без ограничений тарифа.
