# SDR-as-a-Service: автоматизация лидогенерации

Цель: найти первых 5–10 клиентов для SDR-as-a-Service (аутсорс холодных продаж для
раннестадийных B2B SaaS в РФ/СНГ, 5–50 сотрудников) и параллельно выстроить процесс,
который потом можно продавать клиентам как услугу.

Бюджет: **0 ₽/мес**. Стартуем с нуля (без CRM, без списка компаний, без настроенных
каналов) и без единого платного инструмента.

## Важное про бюджет и оплату из РФ

Большинство западных cold-outreach сервисов (Reply.io, Lemlist, Instantly, Apollo,
Clay, платный Airtable) стоят $30–100+/мес **и** часто не принимают российские карты —
они не рассматриваются вообще. Единственная потенциально платная часть в предыдущей
версии этого плана — вызовы Claude API из скриптов — тоже убрана: персонализация и
разбор ответов делаются вручную через **бесплатный чат Claude.ai** (веб/приложение),
пакетно, без API-ключа и без счёта.

## Стек (0 ₽/мес)

| Задача | Инструмент | Стоимость |
|---|---|---|
| База лидов | hh.ru API (публичный) + Google-поиск вручную | 0 ₽ |
| No-code связка/парсинг | Make.com free (1000 операций/мес) | 0 ₽ |
| CRM/трекинг | Google Sheets + Apps Script | 0 ₽ |
| Персонализация сообщений | Claude.ai бесплатный чат (пакетно, вручную) | 0 ₽ |
| Рассылка email | Gmail/Yandex Mail + Apps Script mail-merge | 0 ₽ |
| Уведомления | Apps Script (email) или Telegram Bot | 0 ₽ |
| Квалификация ответов | Claude.ai бесплатный чат (вручную) | 0 ₽ |

Скрипты на Claude API (`personalization/personalize.py`, `qualification/classify_reply.py`)
в репозитории оставлены как **опциональный путь на будущее** — когда появятся первые
платящие клиенты и объём вырастет настолько, что копипастить в чат станет медленнее,
чем платить за API (это будут не десятки, а сотни рублей в месяц). Сейчас основной
путь — ручной, через бесплатный чат, см. `personalization/manual_batch.md` и
`qualification/manual_classify.md`.

## Структура репозитория

- `leads/` — сбор компаний-кандидатов (hh.ru API, схема Make.com)
- `personalization/` — персонализация первой строки: бесплатно вручную через Claude.ai
  чат (`manual_batch.md`) или, позже, платным скриптом через API (`personalize.py`)
- `crm/` — шаблон Google Sheets + Apps Script для трекинга и напоминаний
- `qualification/` — классификация входящих ответов: бесплатно вручную через Claude.ai
  чат (`manual_classify.md`) или, позже, платным скриптом через API (`classify_reply.py`)

## Порядок внедрения (рекомендуемый)

1. Сегодня: создать Google Sheet по шаблону из `crm/` — это ваша CRM.
2. Собрать первые 30–50 компаний вручную или через `leads/` (hh.ru), занести в Sheet.
3. Открыть бесплатный чат на claude.ai, вставить промпт из
   `personalization/manual_batch.md` со списком компаний — получить готовые
   персонализированные строки и скопировать их в Sheet.
4. Первые 5–10 писем/сообщений отправить вручную (на таком объёме автоматизация не нужна,
   зато будет выше качество и отклик) — статусы вести в CRM.
5. Настроить Apps Script напоминания (`crm/apps_script_followup_reminder.gs`), чтобы
   не терять лиды, зависшие на статусе.
6. Когда пойдёт первый поток ответов — разбирать их через
   `qualification/manual_classify.md` в том же бесплатном чате Claude.ai.
