# Уроки агента

Правила из решений и правок владельца. Агент перечитывает этот файл перед каждым текстом и каждым решением.
Новые уроки добавляются через `python3 camirix/agent/autonomy.py learn "<правило>" --example "<пример>"`.
Если урок противоречит facts.yaml или handoff.md, главнее facts.yaml, потом этот файл, потом handoff.md.
