# Персонализация без единого рубля: через бесплатный чат Claude.ai

Никакого API-ключа и счёта не нужно — просто открытый в браузере или приложении
бесплатный аккаунт на claude.ai. Обрабатываем компании пачками (например, по 15–20 за
раз), чтобы укладываться в лимиты бесплатного тарифа (несколько десятков сообщений
в день, лимит обновляется каждые несколько часов).

## Шаги

1. В Google Sheet (лист "Лиды") заполните для очередной пачки компаний колонки
   `Company`, `Domain`, и по возможности `About` (одно предложение о компании —
   скопируйте фразу с сайта или из вакансии на hh.ru, это сильно повышает качество).
2. Скопируйте эти строки (например, из Sheets: выделить → Ctrl+C).
3. Откройте новый чат на claude.ai и вставьте промпт ниже, заменив блок `{{ДАННЫЕ}}`
   на скопированные строки.
4. Claude вернёт таблицу — скопируйте её обратно в колонку `Personalized_Line` в Sheet.

## Промпт для пакетной обработки

```
Ты помогаешь SDR-агентству, которое продаёт услуги холодных продаж B2B SaaS-компаниям
в России и СНГ.

Для каждой компании из списка ниже напиши ОДНУ персонализированную вступительную
строку для холодного сообщения основателю/CEO (email или Telegram).

Правила:
- 1-2 коротких предложения, не больше 30 слов, только на русском.
- Основывайся ТОЛЬКО на данных из списка. Если фактов мало — делай общее, но
  правдоподобное наблюдение про нишу компании. Никогда не выдумывай раунды
  инвестиций, цифры или события, которых нет в данных.
- Никаких клише: "Заметил, что вы...", "Наткнулся на ваш сайт...", "Я изучил ваш продукт и...".
- Тон: как коллега-предприниматель, а не продавец.
- Не упоминай в этой строке предложение SDR-услуг — только открывающая строка.

Верни результат ТАБЛИЦЕЙ с колонками: Company | Domain | Personalized_Line
(без дополнительных пояснений, чтобы можно было сразу скопировать в Google Sheets).

Список компаний:
{{ДАННЫЕ — вставьте сюда строки: Company, Domain, About}}
```

## Совет по объёму

При цели "5–10 первых клиентов" за раз достаточно обрабатывать 15–20 компаний —
это займёт один запрос в чате и пару минут на копирование результата. Делать это
раз в день-два более чем достаточно для темпа ручной рассылки 10–20 сообщений/день.
