# 1. Сбор лидов: B2B SaaS компании (ранняя стадия, РФ/СНГ)

Портрет цели: 5–50 сотрудников, B2B SaaS, есть сайт, ещё не выстроен отдел продаж
(нет вакансий SDR/BDR/Sales Manager с большим штатом продаж — иначе им не нужен ваш аутсорс).

## Вариант A (рекомендуемый на старте): вручную, без инструментов

При цели "5–10 первых клиентов" скорость не главное — важна точность. 30–60 минут в день:

1. Источники для просмотра (бесплатно, без регистрации):
   - vc.ru → раздел "Стартапы" и "Инвестиции" (свежие раунды — сигнал, что у компании
     есть бюджет и нет ещё выстроенных продаж)
   - Rusbase (rb.ru) → лента стартапов
   - getmatch.ru / hh.ru → вакансии "SDR", "Sales Manager", "Account Executive" в SaaS-
     компаниях — если вакансия **одна** и недавняя, значит отдел продаж только строится
   - Каталоги: "Стартап Крауд", Product Hunt (фильтр по географии/языку, часть SaaS из
     СНГ там присутствует)
2. Для каждой подходящей компании фиксируете в CRM (см. `crm/`): название, домен,
   имя основателя/CEO, где нашли контакт (сайт "О нас", LinkedIn, Telegram-канал).
3. Контакт основателя ищем через: сайт компании (раздел "команда"), LinkedIn, Telegram
   (у многих SaaS-основателей в РФ есть публичный канал), либо email по паттерну
   `founder@domain.ru` / `hello@domain.ru` — можно проверить через Hunter.io (бесплатно
   25 проверок/месяц) или NeverBounce free tier.

## Вариант B: no-code автоматизация через Make.com (free tier, 1000 операций/мес)

Схема (Scenario) в Make.com без единой строчки кода:

1. **Модуль 1 — HTTP: Make a request**
   URL: `https://api.hh.ru/vacancies`
   Method: GET
   Query string: `text=SaaS B2B&area=113&per_page=50&page={{номер страницы}}`
   (это публичный API hh.ru, ключ не нужен)
2. **Модуль 2 — JSON: Parse JSON** — распарсить ответ (поле `items`)
3. **Модуль 3 — Iterator** — по массиву `items`
4. **Модуль 4 — Filter** — пропускать только вакансии с `employer.name` не из чёрного
   списка крупных компаний (можно завести отдельный список исключений в Sheet)
5. **Модуль 5 — Google Sheets: Add a Row** — записать `employer.name`,
   `employer.alternate_url` (страница компании на hh.ru, там часто есть сайт),
   `name` (название вакансии), `alternate_url` (ссылка на вакансию) в лист "Сырые лиды"
6. Запускать сценарий раз в день (Scheduling: every day) — новые вакансии = новые кандидаты.

Дальше вручную (10–15 минут/день) проходите по "Сырым лидам", открываете страницу
компании на hh.ru → находите сайт → ищете основателя → переносите готовую запись в
основную CRM (лист "Лиды").

Примеры поисковых фраз для поля `text` в API-запросе (меняйте между запусками):
`SaaS B2B`, `B2B платформа`, `SDR`, `Sales Development Representative`,
`Account Executive SaaS`.

## Вариант C (опционально, если готовы один раз запустить готовый скрипт)

`hh_scraper.py` в этой папке делает то же самое, что схема из варианта B, но локально
и без лимита 1000 операций/мес. Нужен только Python и 5 минут на установку:

```bash
pip install requests
python hh_scraper.py
```

Результат — файл `raw_leads.csv` с колонками: `company`, `hh_url`, `site_url`,
`vacancy_title`, `vacancy_url`. Дальше эти строки вручную проверяются и переносятся
в CRM (домен нужен для шага 2 — персонализации).

Скрипт использует только публичный, бесплатный API hh.ru (без авторизации, без
скрейпинга HTML) — это официальный способ доступа к данным о вакансиях.
